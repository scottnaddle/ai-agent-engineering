# Glossary

## Agent
목표를 달성하기 위해 추론하고, 도구를 사용하고, 반복적으로 행동하는 AI 시스템.

## Tool
에이전트가 외부 세계와 상호작용하기 위해 사용하는 함수, API, 데이터베이스, 검색, 코드 실행 인터페이스.

## Memory
대화 맥락, 장기 저장, 현재 작업 상태를 유지하기 위한 정보 계층.

## MCP
Model Context Protocol. 모델과 도구/데이터 연결을 표준화하기 위한 프로토콜.

## Agentic RAG
단순 검색-응답을 넘어, 계획과 도구 호출, 반복 추론을 포함하는 에이전트형 RAG 구조.
